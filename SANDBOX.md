# Repository Layout

This document describes the structure of the MatchyMatch repository, a collection of puzzle and game components built with React and Vite.

## Top-Level Files and Directories

### Configuration Files
- **.gitignore** - Git configuration to exclude files from version control
- **babel.config.js** - Babel transpiler configuration for JavaScript compatibility
- **eslint.config.js** - ESLint configuration for code quality and style rules
- **jest.config.js** - Jest test runner configuration
- **jest.setup.js** - Jest setup and global test configuration
- **vite.config.js** - Vite build tool configuration for development and production builds

### Package Management
- **package.json** - Project metadata, dependencies, and npm scripts
- **package-lock.json** - Locked versions of all dependencies for reproducible installs

### Documentation
- **README.md** - Main project overview and setup instructions
- **SPEC.md** - Detailed specification of game requirements and features
- **TESTING.md** - Testing guidelines and test coverage information
- **BARRYS_BLITZ.md** - Documentation for the Barry's Blitz game mode
- **COLOUR_CLASH.md** - Documentation for the Colour Clash game
- **COLOUR_CLASH_IMPLEMENTATION.md** - Implementation details for Colour Clash
- **MERGE_RESOLUTION.md** - Notes on merge conflict resolution strategies
- **PINBALL.md** - Documentation for the Pinball game
- **SANDBOX.md** - This file; repository layout documentation

### Build and Deployment
- **index.html** - Entry HTML file for the Vite application
- **.github/** - GitHub-specific configuration (workflows for CI/CD)
- **coverage/** - Test coverage reports generated by Jest

### Source Code
- **src/** - Main application source code
  - **App.jsx** - Root React component
  - **main.jsx** - Application entry point
  - **index.css** - Global styles
  - **components/** - Reusable React components for games and UI
  - **data/** - Game data, puzzles, and word lists
  - **hooks/** - Custom React hooks (e.g., useChessGame, useDarkMode)
  - **utils/** - Utility functions and helpers
  - **styles/** - Additional stylesheet files
  - **assets/** - Static assets like images and SVGs
  - **__tests__/** - Jest test files

### Public Assets
- **public/** - Static files served directly by the web server
  - **favicon.svg** - Website favicon
  - **fonts/** - Custom font files (Roobert family)
  - **icons.svg** - SVG icon sprite sheet

### Utility Scripts
- **scripts/** - Helper scripts for development and maintenance
  - **pick-puzzle.js** - Script to select random puzzles
  - **verify-chains.js** - Script to verify word chain puzzles

### Temporary Files
- **test.txt** - Temporary test file (empty)
