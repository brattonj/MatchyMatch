# Build Setup

This project uses Vite as the build tool and npm for package management. The configuration is defined in `vite.config.js` and `package.json` contains all dependencies and scripts. Babel is configured via `babel.config.js` for JavaScript transpilation. The build outputs to a dist directory and the development server runs on localhost with hot module replacement enabled. ESLint configuration is in `eslint.config.js` for code quality checks.
