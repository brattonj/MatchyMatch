# FORGE-LIMITS-A: Game Components Architecture

This repository contains a comprehensive collection of game board components located in `src/components/`. Each game has its own subdirectory with a dedicated board component.

## Key Game Components

- **Memory Games**: MemoryBoard, CatMatchBoard, MartiniMatchBoard
- **Word Games**: WordleBoard, WordChainBoard, WordSearchBoard, AnagramBoard, ScrambleBoard, SpellingBeeBoard, HangmanBoard
- **Puzzle Games**: SudokuBoard, CrosswordBoard, MinesweeperBoard, Game2048Board
- **Skill Games**: ChessBoard, SnakeBoard, TicTacToeBoard, GreatWallBoard
- **Specialty Games**: BarrysBlitz, ColourClashBoard, TypeRaceBoard, and many others

Each component manages its own game state, rendering, and user interactions independently.
