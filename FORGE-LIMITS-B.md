# FORGE-LIMITS-B: Data Layer and Game Configuration

The `src/data/` directory contains all game data, word lists, and configuration files that power the various games.

## Data Files

- **Word Lists**: anagramWords.js, hangmanWords.js, wordleWords.js, scrambleWords.js
- **Game Data**: memoryCards.js, minesweeperData.js, puppyFetchData.js, game2048Data.js
- **Puzzle Data**: puzzles.js, wordChainPuzzles.js, wordSearchPuzzles.js
- **Quiz Data**: triviaQuestions.js, mathQuizProblems.js, spellingBeeData.js
- **Game Phrases**: typeRacePhrases.js

These data files are imported by their corresponding game components to provide content, difficulty levels, and game configurations.
