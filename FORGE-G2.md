# Game Rules

MatchyMatch is a collection of mini-games including memory matching, word games, chess, sudoku, and more. Each game has its own rules and mechanics defined in individual board components. Games are selected via the GamePicker component and displayed through the GameBoard wrapper. The game data and puzzles are stored in the `src/data` directory with separate files for each game type. Players can toggle between different games and track their progress through the application.
