# Components

The application is built with React components organized in `src/components`. The main App component renders the Header, GameBoard, and Footer. Each game has its own board component (e.g., MemoryBoard, ChessBoard, WordleBoard) located in a subdirectory. Shared components like Tile, Toast, and DarkModeToggle are in the root components folder. The GamePicker allows users to select which game to play. CSS files are co-located with their components for styling.
